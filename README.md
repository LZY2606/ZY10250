# 共振归属工坊

多维 NMR 共振归属工作坊：把实验峰与原子位点组成双部图，在位移容差窗、
重叠容量、单实验排他、跨实验对应与连通证据下，保留多个分数相近的归属方案。
所有结论都固定在导入的峰列版本上。

## 运行

```bash
go mod download
go test ./... -count=1
go run ./cmd/server --listen 127.0.0.1:5590
# 打开 http://127.0.0.1:5590 ，页面标题为「共振归属工坊」
```

默认数据库为当前目录 `workshop.db`（可用 `--db` 指定）。首次启动自动导入
固定 fixture；数据库为空时访问任意接口也会自动导入。

## 数据口径

- **峰列版本**：每次导入产生一个 `versions` 记录；求解结果、运行日志全部
  携带 `version_id`，结论可回溯到具体峰列。
- **实验**：每个实验声明维度核种（如 H/N、H/C）、按核种的容差窗（ppm）、
  每维系统位移偏置（用户可调）与候选窗口（容差单位）。
- **距离尺度**：各维偏移先减去该实验偏置，再除以该（实验，核种）容差，
  以欧氏范数合成归一化距离；绝不把不同量纲的原始 ppm 距离直接相加。
- **重叠峰**：`overlap=true` 且由输入证据声明 `capacity`（fixture 中为 2），
  求解时一个重叠峰最多承载 capacity 个原子，绝不自动无限复用。
- **约束分层**：单实验排他（同一实验内一个原子至多一个峰）在枚举时剪枝；
  跨实验对应（两个实验的峰应指向同一原子）独立校验，只在方案上标注违规，
  不参与剪枝，避免过度剪枝。
- **连通证据**：原子间连通边提供加分；用户可拒绝某条证据，分数即时重算。
- **锁定**：用户锁定的峰-原子对必须出现在方案中；锁定集合自相矛盾时返回
  最小冲突集（删掉其中任意一条即恢复可行），并暂停求解。
- **多方案**：得分与最优解相差不超过 1e-6 的全部不同方案一并返回
  （fixture 中为两个等长最短方案），同时报告未归属峰。

## 固定 fixture

- 2 个实验：HSQC（H/N）、HNCA（H/C，H 维带 0.02 ppm 实验级偏置）。
- 7 个峰：`hsqc-ovl` 为重叠峰（容量 2，窗口内有 3 个候选原子）；
  `hsqc-lone` 无候选，保持未归属。
- 6 个原子位点、3 条顺序连通边、2 条跨实验对应。
- 两个等分最优方案来自 `hsqc-1`/`hsqc-2` 在 Gly1-HN/Ala2-HN 间的对称交换。

## 页面操作

- 调整某实验某核种的系统偏置 → 候选边与方案即时变化（验收点）。
- 在方案列表中锁定/解锁任意峰-原子对。
- 拒绝/恢复任意连通证据。
- 「求解」把一次求解写入运行日志；「导出运行记录」下载 JSON；
  「清空数据库并重新导入」执行复位 + 重新导入 fixture。

## 重放与复核

```bash
# 导出运行记录
curl -s http://127.0.0.1:5590/api/export > run-log.json
# 清空并重新导入（也可直接删除 workshop.db 后重启）
curl -s -X POST http://127.0.0.1:5590/api/reset
```

复位后 fixture 以新版本号重新导入，求解结果与导入前一致
（`internal/store` 测试覆盖该复核路径）。

## API 摘要

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/` | 操作页面（SVG 双部图） |
| GET | `/api/state` | 当前版本状态 + 即时求解结果 |
| POST | `/api/solve` | 求解并写入运行日志 |
| POST | `/api/lock` | `{peak_id, atom_id, locked}` |
| POST | `/api/connectivity` | `{id, rejected}` |
| POST | `/api/bias` | `{experiment_id, nucleus, value}` |
| POST | `/api/reset` | 清空数据库并重新导入 fixture |
| GET | `/api/export` | 导出运行记录 JSON |

```bash
go test ./... -count=1
```

对应分离校验、尺度归一化距离、拒绝连通证据、最小冲突集、锁定破平、
复位重导复核、运行日志导出与页面标题。
