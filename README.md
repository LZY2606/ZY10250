# 共振归属工坊 (Resonance Assignment Workshop)

多维 NMR 共振归属工具：把峰候选与原子位点组成双部图，在局部证据下保留多个
分数相近的归属方案。本地服务使用 Go + SQLite + HTTP + SVG，无外部服务依赖。

## 运行

```sh
go mod download
go test ./... -count=1 && go run ./cmd/server --listen 127.0.0.1:5590
```

访问 http://127.0.0.1:5590 即可看到“共振归属工坊”操作页面。
首次启动若数据库为空会自动导入固定 fixture（`--db` 可改路径，默认 `workshop.db`）。

## 数据口径

- **实验（experiments）**：每个实验有若干维，每维声明核种与容差窗（ppm），
  并带一个可调整的实验级系统位移偏置（每维一个值）。
- **峰（peaks）**：位移、强度、重叠标志与**容量**。重叠峰的容量由输入证据
  显式声明（fixture 中 `P2(ovl)` 容量为 2），求解器绝不自动无限复用；
  未声明时按容量 1（排他）处理。
- **原子位点（atoms / atom_expected）**：每个位点在每个实验下有期望位移。
- **连通证据（connectivities）**：原子对之间的连接（bond/NOE），带权重，
  用于跨实验对应打分；用户可拒绝某条证据。
- **容差匹配**：按（核种 × 实验）分组逐维判定——每一维的偏差都必须落入
  自己的容差窗，**绝不把各维距离直接相加**；打分使用按容差归一化的
  平方和（scaled cost），避免量纲尺度混淆。
- **排他 vs 对应**：同一实验内一个原子最多占一个峰（单实验排他）；
  同一原子在不同实验各占一个峰是合法的跨实验对应，分开校验，不过度剪枝。
- **版本固定**：每次求解结论都记录峰列版本哈希（峰、容差、偏置的 SHA-256
  前 16 位），偏置一旦调整版本即变化。

## 求解语义

- 返回分数相近（与最优分差 ≤ 0.05）的多个方案（最多 5 个），含等长最短并列。
- 未归属峰按最优方案列出；每个归属有奖励、未归属峰有罚分。
- 用户操作：锁定峰-原子对、拒绝连通证据、调整实验偏置。
- 锁定集合不可行时，返回**最小冲突集**（需移除的最少锁定），移除后自动恢复求解。

## 固定 fixture

`internal/store/fixture.go`：

- 一个重叠峰 `P2(ovl)`（容量 2，由输入声明）；
- 两个等长最短归属方案（A1/A2 期望位移相同，交换后分数完全并列）；
- 一次实验级位移偏置：EXP2(HNCO) 的 13C 维存在 +0.2 ppm 系统偏移，
  默认偏置为 0 时峰 `Q2` 无候选、未归属；把实验 2 偏置调为 `[0, 0.2]` 后
  `Q2` 进入候选并被归属——验收时调整偏置即可观察候选变化。

## 重放与复核

- 每次 `POST /api/solve` 都会把操作与结论（含版本哈希）写入 `runs` 表；
  `GET /api/runs` 导出全部运行记录（JSON）。
- 页面“清空并重导 fixture”按钮（或 `POST /api/reset`）会清空数据库并重新
  导入 fixture，之后可重放任意操作序列复核结论。

## API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/` | 操作页面（SVG 双部图、容差窗、连通边、冲突、候选方案） |
| GET | `/api/state` | 数据集 + 默认求解结果 + 候选边 |
| POST | `/api/solve` | 携带 `{Locks, RejectedConn, BiasOverride}` 求解并记录运行 |
| POST | `/api/reset` | 清空数据库并重导 fixture |
| GET | `/api/runs` | 导出运行记录 |

## 测试

```sh
go test ./... -count=1
```

覆盖：等长并列方案、重叠容量上限、偏置改变候选、逐维容差（不跨维相加）、
单实验排他与跨实验对应分离、最小冲突集、容量内锁定可行、拒绝连通证据、
fixture 种子/清空重导、运行日志与 HTTP 端到端。
